Each tool was inspired by existing interactive demos. This page credits the work that shaped what we built — focusing on apps and interfaces, not academic papers.

Neural Network Trainer

interactive-bpann

Mostafa Abdelraouf — github.com/drdrsh/interactive-bpann — MIT license

The Neural Network Trainer is a reskin and substantial extension of Mostafa's work. The core math — feedforward pass, backpropagation, and the ES6 generator-based step-by-step training loop — is adapted directly from his code, as are the key UX concepts: five stepping granularities (node, layer, example, epoch, full run) and the green/gold node color convention for forward pass vs. backpropagation. What this version adds: a canvas renderer, weight-pill labels on edges, a four-slide explainer, a guided tour, and a full visual redesign.

Word Vectors & Bias

Word2Vec Gender Bias Explorer

chanind — github.com/chanind/word2vec-gender-bias-explorer

The closest existing tool to what we built. Its core interaction — type a word, instantly see a bias result — is the right model for a non-technical audience. Our tool extends this to arbitrary analogies (A is to B as C is to ?) and connects the results explicitly to legal and policy contexts.

TensorFlow Embedding Projector

Google Brain team

Demonstrated that high-dimensional word embeddings could be explored meaningfully in a browser with no server and no installation. The right deployment model — though its interface assumes a technical facilitator to interpret the 3D clusters.

ml5.js

NYU ITP / Processing Foundation

Proved the fully-browser-side, zero-install approach was viable for word vector demos. A student can open a URL, wait a few seconds, and start exploring — no Python, no Jupyter, no accounts.
